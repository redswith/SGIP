# Interfaz de SGIP

Aplicación Angular con formularios reactivos, sesión JWT y componentes en español.

- Instalar dependencias: `npm install`.
- Iniciar: `npm run iniciar` (http://localhost:4200).
- Compilar: `npm run compilar`.
- Ejecutar pruebas: `npm run probar -- --watch=false`.
- Formatear fuentes: `npm run formatear`.

Las pantallas están en `src/app/paginas`; los servicios, en `src/app/nucleo`.
La dirección del servidor se configura en `src/entornos/entorno.ts`.
Las palabras reservadas de TypeScript, HTML, CSS y Angular conservan su sintaxis original.
